# AI Prompts

Five standalone Claude prompts for reviewing this project: full project review, documentation review, README review, SQL refactoring, and validation checks. These are copy-paste prompts for ad hoc use, not live Claude Code configuration.

Two other things that also count as "AI-related" are **not** here, on purpose:

- **`.claude/skills/`** and **`.claude/commands/`** — Claude Code auto-discovers these only from that exact path. Moving them out of `.claude/` would stop them from working.
- **`CLAUDE.md`** (repo root) — Claude Code auto-loads this only from the project root.
